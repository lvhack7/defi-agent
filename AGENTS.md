
# DeFi Autopilot

We are building an autonomous DeFi treasury
management agent using ZooWork Managed Agents,
TypeScript, viem, and Uniswap.

## ZooWork SDK

Before implementing or modifying ZooWork
integrations, consult the installed
`zoowork-managed-agents` skill and its references.

Follow the documented SDK patterns for:
- Agent creation and configuration
- Sessions and event streaming
- Custom tool registration and resolution
- Error handling and deployment

Never invent ZooWork SDK APIs.

## Development priorities

1. Working ZooWork agent
2. Blockchain read-only tools
3. Uniswap quote integration
4. Policy-controlled transaction execution
5. Next.js dashboard
